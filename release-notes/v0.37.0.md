# Leash 0.37.0

Leash 0.37.0 makes the public product personal-only and moves every shipped
security and productivity capability into the client API as a built-in
Feature.

## Highlights

- Renamed the user-facing product from OpenLeash to Leash while preserving
  compatibility identifiers used by existing installs.
- Removed the public dashboard, dashboard API application, identity-loader,
  private-cloud deployment, organization onboarding, and third-party Feature
  marketplace surfaces.
- Replaced containerized plugins with a closed, typed registry of first-party
  in-process Features. Unknown handlers cannot be dynamically loaded.
- Kept stable Feature IDs and `/v1/plugins` compatibility routes, while retired
  marketplace and upload routes now return a deterministic `410 Gone`.
- Replaced organization bootstrap with a single personal-profile bootstrap.
- Updated desktop, mobile, website, docs, flow viewer, installer, and release
  tooling for the Leash name and personal product flow.
- Upgraded Electron to 43.3.0 to include the current sandbox navigation fix.
- Added native macOS and Windows release workflows for `Leash-0.37.0` desktop
  artifacts.
