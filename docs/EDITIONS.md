# Leash Modes

| Mode | Backend | Account | Evaluation | Features |
|---|---|---|---|---|
| Leash Cloud | Hosted client API | Personal cloud account | Managed or BYOK | First-party, in process |
| Personal Open Source | Local client API + Postgres | Local bootstrap | BYOK | First-party, in process |

Both modes are for individual developers. No public organization/dashboard edition is shipped.
