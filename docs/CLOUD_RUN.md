# Hosted Operations

Hosted production deployment runbooks are OpenLeash-operated infrastructure material and should not be published as customer installation docs.

Customer-facing deployment docs should explain:

- how individuals install the desktop, Windows, or mobile clients
- how organization admins sign in and complete dashboard onboarding
- how admins configure identity, roles, policies, provider usage, first-party plugins, external-agent connectors, and update mode
- how admins create deployment tokens
- how admins roll out the desktop app through MDM or internal software distribution
- how employees sign in and receive dashboard-managed configuration
- how self-hosted operators run the open-source Private Cloud stack without relying on OpenLeash-operated hosted infrastructure

Keep hosted-only project names, service hostnames, image paths, build commands, and operations topology in the private hosted runbook.
