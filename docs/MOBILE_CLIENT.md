# Leash mobile client

Leash Mobile is the iOS and Android companion for a personal Leash account. It connects to the same `client-api` as desktop, registers the device, shows personal agent activity, and resolves approvals or structured questions.

The mobile client supports Leash Cloud. A Personal Open Source user may provide a reachable custom API URL; localhost on another computer is not reachable without a tunnel, VPN, or LAN address.

Mobile has no dashboard, organization selector, SSO discovery, identity-provider configuration, marketplace, publisher, rating, or download-count UI.

Question and approval notifications use the same notification-sound preference as web and desktop where platform policy allows it.
