# Leash roadmap

1. Make personal Leash monitoring reliable across supported agents, editors, displays, sleep/wake, hooks, and the local proxy.
2. Keep every built-in Feature deterministic, observable, configurable, and covered by fixture plus end-to-end tests.
3. Ship signed macOS and Windows desktop builds with verified update feeds.
4. Keep Personal Open Source on the same `client-api`, Postgres migrations, Feature registry, and client contracts as Leash Cloud.
5. Improve mobile and web approval parity without introducing organization or dashboard surfaces.

Leash does not plan a public Feature marketplace, third-party upload flow, public dashboard, dashboard API, or identity-provider service.
