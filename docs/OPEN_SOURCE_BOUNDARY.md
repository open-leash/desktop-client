# Open-Source Boundary

This repository contains the complete personal runtime monorepo: Leash Engine,
Desktop, Mobile, local proxy, provider sync worker, flow viewer, shared
contracts, database schema/migrations, personal deployment tooling, and all
first-party Feature implementations.

The public documentation site remains a separate public repository.

Not public: the marketing/account website, hosted `cloud-client-api`, dashboard
UI/API, organization administration, customer identity-provider services,
billing, hosted provisioning, production credentials, abuse controls, and
internal cloud operations.

Features are not independently uploaded packages. They are reviewed Leash
source compiled into Engine and released with the runtime.
