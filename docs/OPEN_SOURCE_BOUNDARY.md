# Open-Source Boundary

Public: `desktop-client`, `mobile-client`, `client-api`, `local-proxy`, `provider-puller`, `main-web`, `docs-web`, `flow-viewer`, shared contracts, database schema, personal deployment, and all first-party Feature implementations.

Not public: dashboard UI/API, organization administration, customer identity-provider services, billing, hosted provisioning, production credentials, abuse controls, and internal cloud operations.

Features are not independently uploaded packages. They are reviewed Leash source compiled into `client-api` and released with the product.
